# Closed GET query-copy effects

Status: accepted amendment to the [X7 design](x7-upper-length.md), implemented in 0.1.0 (`packages/extract-contracts/src/write-query-copy-*.ts`; status checked 2026-11-10). [Closed query-copy implementation limits](../evaluation/closed-query-copy.md) records what the implementation admits and refuses; the real-source acceptance below is unmet.

Implementation may rely on this amendment only after the amendment is accepted. That permission does not establish implementation, real-source acceptance, qualification or release readiness.

## Named consumer and problem

The consumer is the source-proved request parser and complete client-cache safety walk in the X7 producer work ([X7](x7-upper-length.md)). The pinned [parent parser](https://github.com/umami-software/umami/blob/c0ea3aefbee7a3429ee2f824b06dc4a9dbe0b7e1/src/lib/request.ts#L20-L40) has a query-copy loop in its successful GET branch. The required POST proof does not execute that branch, but the source-world cache check must also account for other invocations that could execute it.

The [X7 design](x7-upper-length.md) permits exclusion of a proved disjoint branch. That does not grant a general exception for unknown computed extraction. Computed calls still require the existing bounded finite literal-key proof. Unknown computed reads, getters, proxies, aliases and capability extraction still withhold unless the complete certificate below proves the two data-copy accesses safe. A parser-local non-GET argument alone cannot waive a source-world check.

## Required certificate

1. Prove the existing parser shape first: a const method test against GET, the conditional safeParse input, the success discriminator, the successful non-GET body assignment, callable failure error, guarded caller and unchanged returned bindings. The relevant caller must have the existing source-proved non-GET framework method. A function name or filename alone supplies no method evidence.
2. Prove the original query is a fresh ordinary string-valued record constructed by unshadowed intrinsic URL, URLSearchParams and Object.fromEntries operations from the request URL. The saved query is an immutable alias of that exact record. Account for every alias, read, write and escape before the copy. A shared object, custom iterator, getter, proxy, unknown constructor or namespace rewrite cannot supply this provenance.
3. Prove that validation cannot mutate the saved input into a capability-bearing object, and that its successful query result is a fresh ordinary record with safe property-write behavior. A method merely named safeParse is insufficient. Any library summary must have a reviewed exact version, full lock integrity, primary source citation and static-table equality to the reviewed artifact before use, with patches, overrides, mutation and source substitution refused. Root transforms, arbitrary validation methods, callbacks receiving the whole query, callable values, proxies and unresolved alias effects do not receive credit without their own bounded proof.
4. For source-world reuse, account for every in-repository reference and possible invocation of the parser, including imports, re-exports and aliases. A source-proved non-GET invocation cannot execute the copy. Every invocation that could execute it must meet the query and validator provenance above. An unresolved call, escape, caller set, mutation or inventory invalidates this source-world certificate. Do not reuse a single caller's parser proof as proof about every caller. The established boundary is inspected repository source, not protection against arbitrary injected globals or external runtime state.
5. Match a closed loop: first assign the parsed data to the query; then permit at most one synchronous for-of over unshadowed Object.keys of the saved record, with one const identifier and no defaults, destructuring, await, extra statements, calls other than the specified Object.keys and literal-regex test, hoisted declarations or escapes. Its sole body is an if with a literal digit-suffix test and an exact short-circuit absence test for the same key in the destination. Its sole effect copies the saved record's value at that same key into the destination. Source, destination and key must agree by lexical binding, including under shadowing.
6. Match the digit test as syntax from a reviewed closed table, initially the decimal-digit suffix regex literals `/\d+$/` and `/[0-9]+$/`, without stateful g or y flags. Never execute an input regular expression, enumerate possible keys or unroll the loop. These strings describe an infinite data-key domain; they do not establish a finite literal-key capability proof. The object/value provenance and complete use checks are necessary in addition to excluding capability property names.

A successful certificate may identify only the two exact element-access AST nodes in that proved copy. The parser and source-world client checks must derive the same shared certificate before accepting either node. All other dynamic code, computed reads and computed call checks remain active, including other expressions in the same function or file. An unproved shape receives the original strict guard and a stable refusal. No blanket subtree exclusion, path/function-name allow-list or fallback to a weaker guard is permitted.

## Bounds and acceptance

Keep the existing two forwarding boundaries, four-function client initialization limit, 32 resolved modules, 64 resolutions per module, 10000 binding-slice syntax nodes, complete 20000-entry source inventory, 8 MiB per-file limit, 8 MiB/2048-entry input cache, and 512 MiB/120-second child limits. Count the complete proposed function before summarizing it. Source-world walks remain complete and bounded separately as specified by X7; a cache cannot erase recorded binding-slice charges. Exhaustion or missing provenance is UNKNOWN, never a shortened proof or an examined negative.

Use original generic fixtures and actual pinned source without executing, installing or copying upstream application code. Required controls include the previous unguarded loop refusal; guarded but callable, shared, mutated, getter/proxy or escaped query records; unsupported schema artifacts; hidden or unknown callers; shadowed intrinsics; var or await loops; changed receivers, keys, operators and guards; extra effects; and computed extraction elsewhere in the same function and source world. Mutations removing provenance, all-caller closure, exact-node confinement and the digit guard must fail outcome assertions.

Then rerun the exact required parent and fix through production extraction and evaluation on the isolated host. Show the parent contradiction and examined fixed negative, or preserve and report the measured refusal. A passing fixture, a parser-only result, different upstream revision, renamed target or historical firing cannot substitute for that proof. Preserve ADR-0017 identity, ADR-0018 authority, fresh independent source reviews, exact-head verification and the original sealed qualification and per-detector recall requirements. This amendment supplies no new detector result or qualification credit.
