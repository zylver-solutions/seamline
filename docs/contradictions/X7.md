## What it compares

X7 follows `COLUMN_TO_PROPERTY` from a fact `Column` to a fact request `SchemaProperty`. The column must explicitly declare a finite nonnegative integer `maxLength` and a scalar text type. The property must positively establish an unbounded string validator and a complete validated write binding to that exact storage model, table and field. The contracts extractor emits those facts only within its [bounded source grammar](../../packages/extract-contracts/README.md).

A finding means that the validated input permits strings longer than the declared storage bound along the extracted binding. It does not assert an executed request, a database exception or an HTTP response. The detector does not compare validator Symbols or infer an unbounded validator from an absent constraint.

## Required evidence

Both endpoints and their containing Table and Contract must be live facts. The table must identify the same Prisma model as the property, and the property's storage table and field must identify that column. The property must state `direction: request`, `valueRole: validated-write-input`, `successfulParse: true`, `unchangedForwarding: true`, `modelBindingComplete: true` and `writeBindingComplete: true`.

`lengthUpperState: unbounded` is positive producer evidence from the supported grammar. A missing state, unsupported operation, unknown limit or incomplete binding is not evidence of unbounded input. A `bounded` property with a valid literal maximum is an examined negative, including a stricter or looser bound. Comparing two unequal stated limits remains [X3](X3.md)'s deferred subject.

## Current-run authority

The host supplies successful authoritative claims from the latest finished run through `packages/cli/src/current-observation.ts`. Every endpoint and container must be within the corresponding current claim, have that run's stamp and belong to its repository. Join hops must share the property run stamp. A live retained fact outside the latest selector is insufficient, even if a deterministic run id repeats.

The CLI integration test `packages/cli/src/validated-write-lifecycle.test.ts` uses real extraction, SQLite and join inference. It checks a supported binding, supported-to-unknown transitions that retain earlier facts outside authority, and recovery to bounded inputs. `packages/cli/src/current-observation.test.ts` separately checks finished-run, scope, selector, liveness and repository conditions. A bare graph without host authority cannot establish X7 currentness.

## UNKNOWN and negative results

An unavailable required scope is UNKNOWN. A successful scope without any current supported length pair is also UNKNOWN, with `X7_NO_OBSERVABLE_LENGTH_PAIR`. Missing current-run metadata reports `X7_CURRENT_RUN_UNAVAILABLE`. An unsupported contract is withheld or its affected property is marked incomplete; neither supplies a finding. A proved pair with an explicit input bound can establish a negative result.

## Confidence and controls

The join confidence multiplies along inferred hops, with the central confidence floor and severity ceiling unchanged. Non-fact endpoints, tombstones, suggested edges, response-only properties and incomplete parse/forward/model flags cannot produce a finding. The detector tests and `packages/contradictions/src/meta.test.ts` cover firing and bounded negative controls; the retired synthetic Symbol constraint route is a negative control.

## Validation boundary

The [historical pinned proof](../evaluation/x7-parent-fix.md) includes earlier parent/fix CLI output and source guard mutations. [Later hardening refusals](../evaluation/x7-hardening-refusals.md) supersede its firing coverage; the required actual-parent proof remains unmet. Byte-reproducibility, fresh review councils, full repository gates and independent qualification remain separate requirements. Authored fixtures do not establish external precision or mutant recall. The historical zero-finding evaluation remains historical evidence; a new development result must be reported separately. Sealed qualification still requires at least 30 independently labelled clusters, precision at least 0.9 and a Wilson lower bound at least 0.75.
